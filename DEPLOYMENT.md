# 🚀 Deployment Guide — Health Intelligence System

This repository is pre-configured with a **Render Blueprint (`render.yaml`)** to deploy the complete stack with a single click:
1. **Managed PostgreSQL Database** (`health-db`)
2. **Backend Web Service** (FastAPI + PyTorch Docker container)
3. **Frontend Static Site** (React 18 + Vite CDN distribution)

---

## ⚡ Quick Deployment (Automated Blueprint)

### Step 1: Push Changes to GitHub
Make sure all your changes and `render.yaml` are pushed to your GitHub repository:
```bash
git add .
git commit -m "Add Render deployment blueprint and production configuration"
git push origin main
```

### Step 2: Connect Repository to Render
1. Go to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** in the top navigation and select **Blueprint**.
3. Select your repository: `Sathvik-C/AI-Health-Intelligence-System`.
4. Render will parse [`render.yaml`](./render.yaml) and automatically create:
   - `health-intelligence-db` (PostgreSQL Database)
   - `health-intelligence-backend` (Docker Web Service)
   - `health-intelligence-frontend` (Static Site)

### Step 3: Set Your Environment Secrets
During blueprint creation (or under Backend > Environment in the Render dashboard):
- **`GEMINI_API_KEY`**: Enter your Google Gemini API key.
- **`SECRET_KEY`**: Automatically generated by Render (or provide your custom JWT secret).
- **`ECG_DEMO_MODE`**: Set to `"true"` (recommended for free tier memory efficiency) or `"false"` to download full ConvNeXt-Tiny weights.

### Step 4: Click "Apply"
Render will:
1. Provision your PostgreSQL database.
2. Build the Docker container for FastAPI and link the database connection string automatically.
3. Build the React frontend with `npm run build` and connect it to your backend's live URL.
4. Issue free SSL certificates for both domains.

## 🔧 Production Configuration Details

| Component | Service Type | Runtime / Spec | Port / Routing |
|---|---|---|---|
| **Frontend** | Static Site | Vite / Node 20 | `/*` rewritten to `/index.html` (SPA) |
| **Backend** | Web Service | Docker (Python 3.11) | Reads `$PORT` (Render dynamic port) |
| **Database** | PostgreSQL | PostgreSQL 16 | Auto-connected via `DATABASE_URL` |

### Environment Variables Reference

| Variable | Target Service | Purpose |
|---|---|---|
| `DATABASE_URL` | Backend | Connection string injected from PostgreSQL |
| `SECRET_KEY` | Backend | JWT token signing secret |
| `GEMINI_API_KEY` | Backend | Google Gemini API key for lab report extraction & chatbot |
| `ECG_DEMO_MODE` | Backend | Set to `true` for simulated ECG demo or `false` for full model |
| `VITE_API_URL` | Frontend | Automatically set to the backend's live domain |
